## Using TreeShift

### Left sidebar: the model

Model settings come first: what to map (a species, forest type, or the whole tree community), the raster grid, climate scenario, bandwidths, and landscape connectivity. They take effect when you press `Run model`. Display settings below them, such as which results are drawn on the map, apply right away.

### Map

Click the map to set a focal site. Several panels use it: they show which plots inform the value there, which places share its climate, and summarize modeled results at the focal site and its the surrounding area.

### Right sidebar: modules

Each panel has its own controls and figures: community composition, value distributions across areas, climate relationships, model evaluation, climate models, and focal site analogs.

### Help

Hover over any control for an explanation.

### Sharing and citing results

The URL address always holds the current model settings. In the `Export` panel, `Copy link` copies it, and anyone who opens the link gets the same settings, though results can change if the app or its data are updated later. `Download settings record` saves a text file with the link, a plain language summary of every setting, and the versions of the app and data behind the result. Keep it with any maps or numbers you report.

### Downloads

The `Export` panel also downloads the current map as a GeoTIFF and the FIA plot values as a CSV.
